How analysis works

  1. Upload — the file is stored privately and its type is verified. Unsupported files are rejected without starting analysis.
  2. Static analysis — Rikune profiles the binary and maps its functions to build reviewable evidence.
  3. Promote — advance to a deeper stage when you need more detail. Dynamic execution is not available in this version.
  4. Ask — start a conversation grounded in the collected evidence. Answers cite the evidence they rely on.

Limits: up to 25 active analyses, 3 analyzing at once, and 10 GiB of storage per person.
